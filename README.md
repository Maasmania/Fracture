# FRACTURE

Voxel destruction FPS. This repo feeds the game's auto-updater (version.json + index.html) and holds the online server (server.js, package.json, setup.sh).

Server install/update on the VPS (as root):

    curl -fsSL https://raw.githubusercontent.com/Maasmania/Fracture/main/setup.sh | bash

Current version: 1.0.1
